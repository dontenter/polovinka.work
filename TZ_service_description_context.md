# Доработка сервиса Game Testing (polovinka.work) — сбор контекста для генерации описаний

Дата: 2026-06-11
Основа: `TZ_v2_crazygames.md` (промпт генерации) + `report/crazygames_description_patterns.md` (анализ 4135 страниц CrazyGames)

Язык заполнения — **русский**: редактор вносит всё по-русски, перевод на английский — отдельный шаг перед подачей в промпт. Исключение — названия из игры (режимы, персонажи, предметы, клавиши): остаются точно как в интерфейсе игры, обычно латиницей.

## 2.4. Deep-content блоки (то, что CrazyGames выносит в подзаголовки)

По анализу CrazyGames: 45% страниц (1890/4135) имеют содержательные подзаголовки, ещё 22% — «жирные» лид-фрагменты без заголовка. В среднем 1.4 блока на игру при медиане описания 75 слов → блоков много на выбор, но заполняются обычно 1–2; все опциональны, форсировать заполнение нельзя.

### Общие правила для всех блоков

| Правило | Как работает в UI | Откуда требование |
|---|---|---|
| Порог 2 элементов | Блок попадает на страницу только при ≥ 2 названных элементах (или одном развёрнутом авторском фрагменте). При < 2 — серая плашка «не попадёт на страницу, факт уйдёт в основной текст» | Промпт, Deep-Content Subheadings, THRESHOLD |
| Названия как в игре | Имена режимов/персонажей/предметов/клавиш вводятся дословно из игры (латиницей); из них строится bold-формат `<li><b>Название</b>: деталь</li>` | Промпт, NOUN & NUMBER AUDIT |
| Свой ярлык блока | Если игра называет раздел иначе (Worlds вместо Levels) — редактор переопределяет ярлык, промпт зеркалит авторский лейбл | Промпт, «headings are data» |
| Счётчик элементов | На свёрнутом блоке аккордеона виден счётчик заполненных строк | UX |
| Сериализация | Каждый заполненный блок приклеивается в `description` литеральным labelled-списком («Game Modes:», «Key features:», «Tips:» + строки) — только литеральный список даёт промпту право создать секцию | Промпт, существование Key Features / h3 |

### Блоки формы (приоритет = частотность у CrazyGames)

| # | Блок | CrazyGames: частота и примеры | Поля UI | Подсказка редактору / правила |
|---|---|---|---|---|
| 1 | **Key Features** | 27% игр (1128); заголовок «Features» у 986. В лид-фрагментах: Customization (5), Achievements (4), Rewards (3), Resource Management (3) | Повторяемые bullet-строки; для названных элементов — пара «Название + деталь» | «Только то, что реально есть в игре — список попадёт на страницу почти дословно. Кандидаты: режимы, число уровней, мультиплеер, кастомизация, ачивки, дейлики». Отдельные блоки под Customization/Achievements не нужны — это пункты Features |
| 2 | **Tips & Tricks / Strategy** | 6% (277); «Tips» (70), «Tips & Tricks» (24), «Strategy» (14), «Game Tips» (7), «Guide» (7); лид-фрагменты Strategy (25), Tips (22) | Повторяемые строки-советы + чекбокс «продвинутая техника» на строке | «Реальные советы из вашего прохождения, не "have fun" — совет из общих знаний жанра промпт отбросит». При ≥ 2 строк с чекбоксом — сериализуем отдельным лейблом «Advanced Moves:» (у CrazyGames 68 игр: «Flips & Combos», «Unlock new combos»). Если совет отвечает на вопрос игрока («What is the best strategy…») — он же кандидат в анкету, но факт живёт в одном месте: либо Tips, либо FAQ |
| 3 | **Upgrades / Progression / Economy** | 5% (243): «The Shop In Between Levels», «Buy upgrades», «Buy and upgrade your defenses» | Textarea + строки «Что улучшается → за что покупается»; поле «название внутриигровой валюты» | **Критично:** «Связку "зарабатываешь X → покупаешь Y" писать ТОЛЬКО если видели её в игре явно — недоказанную причинно-следственную связку промпт удалит целиком (NO SYNTHESIZED RELATIONSHIPS)» |
| 4 | **Levels / Maps / Worlds** | 4% (197): «Every Level Has A Monetary Goal», «What to expect from the Easy level» | Числовое поле «количество уровней» (только integer) + textarea «структура»; переключатель ярлыка Levels/Worlds/Maps/Stages | «Только точное число — "около 30" и "десятки уровней" промпт писать не имеет права. Не уверены — оставьте число пустым и опишите структуру словами (миры, сложности, что меняется между уровнями)» |
| 5 | **Game Modes** | 4% (183); «Game Modes» (41), «1 Player Mode» (17), «2 Player Mode» (13); лид-фрагменты Endless Mode, Single Player Mode, Battle Royale, «Two/Multiple game modes» | Строки «Название режима + 1 фраза, чем отличается» | «Минимум 2 НАЗВАННЫХ режима. Нельзя выдумывать ярлык для обычной игры ("Classic mode"), чтобы добрать до двух — один реальный режим уйдёт строкой в How to Play». Названия — дословно из UI игры (Sandbox Mode, Apopolypse Mode). Разное управление в режимах → сигнал заполнить раздельные контролы (Player 1/Player 2 — по ~60 игр у CrazyGames) |
| 6 | **Vehicles / Cars** | 3% (148) | Строки «Название транспорта + деталь» | Показывать блок выше в списке при тегах racing/driving/car. Деталь (скорость, как открывается) — только если игра это показывает |
| 7 | **Characters / Heroes / Skins** | 3% (142): «Happy Wheels Characters», «Newer Characters», «Customize your character» | Строки «Имя персонажа/скина + деталь» | «Минимум 2 названных персонажа. "Есть разные скины" без названий — это пункт Key Features, не отдельный блок». Автотриггер из чек-листа (см. §3) |
| 8 | **Weapons / Gear / Items** | 2% (117); «Weapons» (38): «What is the best weapon in Pixel Warfare?», «Secondary Weapons and Power-ups» | Строки «Название + деталь»; переключатель ярлыка Weapons/Items/Gear; кнопка ★ «лучший элемент» | ★ на элементе → предлагается вопросом в анкету («best [weapon]» — один из intent-шаблонов промпта и частый паттерн FAQ у CrazyGames) |
| 9 | **Enemies / Bosses** | 1% (76); лид-фрагмент «Epic Boss Battles» | Строки «Название врага/босса + деталь (где встречается, чем опасен)» | «Поведение описывайте словами игры, не аналитическими ярлыками: "AI-controlled entity" — запрещено, "Granny hunts by sound" — можно» |
| 10 | **Power-ups / Abilities** | 1% (55): «Use power-ups to turbo-charge the ball» | Строки «Название пауэр-апа + эффект» | Стандартные правила: порог 2, названия из игры |
| 11 | **Story / Setting** | В TZ разрешён; у CrazyGames заметен в лид-фрагментах | Короткое textarea | «Только то, что игра сама показывает (интро, катсцены, тексты). Додумывать предысторию и цели персонажей нельзя» |

### 12. Анкета — 4 фиксированные группы вопросов (единственный источник FAQ)

FAQ на странице рождается **только** из анкеты — промпт детектит её по литеральным заголовкам групп и маркерам «Q:/A:». Группы в UI — с русскими названиями:

| Группа в UI (рус) | Литеральный маркер при сериализации | Пресеты вопросов (рус) |
|---|---|---|
| Базовый геймплей и сюжет | `Core Gameplay & Story` | В чём цель игры? Как победить / что считается проигрышем? Есть ли сюжет? Что цепляет в первые минуты? |
| Механики и прогрессия | `Mechanics & Progression` | Сколько уровней / понятна ли структура? Что открывается по мере игры? Меняется ли сложность? Сохраняется ли прогресс? |
| Экономика и кастомизация | `Economy & Customization` | Есть ли внутриигровая валюта и магазин? Что можно купить/улучшить? Есть ли скины / кастомизация? Что доступно с самого старта? |
| Удержание и вовлечение | `Retention & Engagement` | Есть ли дейлики / колесо фортуны / ачивки / таски? Есть ли лидерборды и как работают? Нужен ли звук? Планируются ли обновления контента? |

| Правило UI анкеты | Детали |
|---|---|
| Пары «Вопрос / Ответ» | Повторяемые внутри каждой группы; вопрос из пресетов или свой |
| Счётчик | «Заполнено N пар. Для FAQ нужно ≥ 2 содержательных ответа (цель 3–6, максимум 8)» — пороги из промпта |
| Ответ «нет» | Плашка «пара будет пропущена»; негативный ответ полезен, только если негация — польза игроку («всё открыто со старта», «уровней нет — сложность подстраивается») |
| Фильтр монетизации | В группе «Экономика и кастомизация» жёлтая подсветка слов про рекламу / покупки-или-реклама — промпт обязан их вырезать (Brand Safety); пишем только игровую часть факта |
| Сериализация (критично) | После перевода анкета приклеивается в КОНЕЦ поля `description`: литеральный английский заголовок группы из таблицы выше, затем пары `Q: …` / `A: …`. Русские названия групп — только для UI; без оригинальных маркеров генератор не имеет права создать FAQ |

```
{проза разработчика}

Core Gameplay & Story
Q: ...
A: ...

Mechanics & Progression
Q: ...
A: ...
```

## 3. Автозаполнение из чек-листа (главный выигрыш сервиса)

Редактор уже отвечает на вопросы, которые являются готовыми фактами для страницы. Ничего не уходит в промпт автоматически — редактор подтверждает/правит каждый черновик.

| Пункт чек-листа / рейтинга | Куда идёт черновик факта |
|---|---|
| «После перезагрузки страницы прогресс сохраняется» = Yes | Анкета («Механики и прогрессия») → В: Сохраняется ли прогресс? / О: Прогресс сохраняется между сессиями |
| Лидерборды (фича отмечена + проверки пройдены) | Анкета («Удержание и вовлечение») → В: Есть ли лидерборды? + кандидат в Key Features |
| Мультиплеер отмечен и работает | Key Features + анкета; тестировали Desktop+мобилку → триггер раздельных контролов |
| «В игре есть разные персонажи / скины» | Раскрыть блок Characters/Skins, попросить 2+ названия; без названий — пункт Key Features |
| «Есть прогрессия у игрока или в уровнях» | Раскрыть блок Upgrades/Progression, попросить детализировать |
| «Дейлики, колесо фортуны, ачивки, таски — есть что-то из этого» | Анкета («Удержание и вовлечение») + кандидаты в Key Features (Achievements/Rewards — типичные пункты Features у CrazyGames) |
| «Если есть несколько языков — игра подстраивается» | Анкета → факт локализации |
| «Есть интро-уровень с онбордингом», «Управление объясняется» | How to play (наблюдения) + подсказка заполнить Tips для первых шагов |
| «Первые уровни лёгкие? Быстрый первый результат?» | Кандидат в Tips & Tricks («с чего начать») |
| «В игре есть разнообразие контента» (рейтинг) | Напоминание заполнить Game Modes / Levels / Weapons — что именно даёт разнообразие |
| «Если есть моб. поддержка — работает без проблем» | НЕ передавать как «mobile platform» (платформы запрещены промптом); только триггер спросить раздельные контролы PC/Mobile |

| Что НИКОГДА не передаём в контекст | Причина |
|---|---|
| Всё про рекламу и монетизацию: Interstitial/Rewarded работают, «можно продолжать без реворда», Smart Ads, Anzu, ин-апы | Промпт обязан вычищать любые упоминания ads/monetization (Brand Safety) — мусор на входе |
| Крэши, кривой UI, спорный контент/IP, вес билда, «игра от крупной студии», «сделана на ИИ» | Внутренняя модерация, не контент страницы |

**Механика UX:** после прохождения чек-листа сервис показывает панель «Из ваших ответов собрано N черновиков фактов» — список галочек-предложений с возможностью отредактировать формулировку. Принятые уходят в соответствующие поля контекста (анкета / Key Features / deep-блоки). Редактор тратит на контекст 2–3 минуты вместо заполнения формы с нуля.
